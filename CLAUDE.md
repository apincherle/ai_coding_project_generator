# Claude Repository Entry Point

Read `AGENTS.md` first. Then discover the product context filename from `.ai/generation.json`; in a
generated project this is the root `<ProjectName>.md` file. Read that file and all applicable `.ai/*.md`
standards before acting. Use only context-approved libraries and tools, run the relevant verification, and
leave all Git staging, commits, pushes and pull-request actions to a human.
