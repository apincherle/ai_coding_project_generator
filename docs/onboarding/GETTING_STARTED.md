# Getting Started

Install Java 21, Maven 3.9+, Docker, Git, and your organisation-approved AI client.
Read `README.md`, `AGENTS.md`, and `.ai/`. Configure hooks with
`git config core.hooksPath hooks`. Copy `.mcp/servers.example.json` only after security approval;
keep credentials in environment variables. Run `scripts/verify.ps1` or `scripts/verify.sh`.
For a new change, invoke a workflow from `.ai/skills.md`, open a PR, disclose AI assistance,
and attach validation evidence.
