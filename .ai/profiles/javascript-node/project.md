# Project Context - JavaScript Node Profile

Baseline: organisation-approved Node.js LTS, modern ECMAScript modules, JSDoc/type checking where practical,
and the selected server framework such as Fastify or Express.
Testing: Vitest or Jest, Supertest where appropriate, Testcontainers and contract tests.
Quality: Prettier, ESLint, Node type checking/JSDoc policy, coverage, dependency scanning and Semgrep.

Use this profile only when TypeScript is deliberately not selected. Document the reason, module system,
selected framework, package manager, owners, data classification and runtime/deployment constraints.
