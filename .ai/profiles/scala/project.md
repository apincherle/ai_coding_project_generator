# Project Context - Scala Profile

Baseline: Scala 3, the organisation-approved JDK, sbt or scala-cli, and the selected HTTP/data framework.
Testing: MUnit or ScalaTest, Mockito Scala only at real boundaries, property tests and Testcontainers.
Quality: Scalafmt, Scalafix, compiler warnings, coverage, dependency scanning and Semgrep.

Replace this paragraph with the product purpose, selected framework (for example http4s, Pekko HTTP or Play),
effect system, owners, data classification, JDK/Scala compatibility and external interfaces.
AI may implement scoped changes, but a named human owns requirements, review and release.
